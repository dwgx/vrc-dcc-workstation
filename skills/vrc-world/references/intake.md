# Read-only world intake

Start from an **explicit authorized directory**. Read known project files only: `ProjectSettings/ProjectVersion.txt`, `Packages/manifest.json`, package lock, VPM lock. Open a scene YAML only when the target path is already identified and the question needs it. Do not walk drives or credential directories.

Disk facts prove declared versions, file hashes, and source references. They do not prove active Editor identity, unsaved state, successful import, compiled Udon, or headset performance.

An already-connected, correctly identified Editor may provide separately authorized read-only evidence. Do not boot MCP or Unity to complete a report silently.

If the owner asked for a return pack, typical files are `ENV_REPORT.md`, `LOCAL_SOURCE_MAP.json`, `BLOCKERS.md`, `NEXT_ACTION.md`. Creating that directory must itself be allowed. Stop after the report.

Received asset copies and desktop originals keep separate identities (bytes + pixel hash). Size differences are not proof of corruption. Do not overwrite sources to “standardize 2K”.
