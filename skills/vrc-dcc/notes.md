# Notes protocol

Station memory lives in `notes/` plus `maps/` in this clone.

Chat and jsonl are not a substitute. Find on demand: `maps/query.py`. Booth playbook: `maps/AGENT.md` when the slice is find. Handshake: CURRENT + `handshake.py`.

Write when a pin, path, SDK quirk, or failed approach will still matter next week. Do not write secrets, SDK cookies, or session dumps.

Format: `YYYY-MM-DD-slug.md` + front matter `tags`, `status` (`observed` / `verified` / `blocked`), `source`. Link from `INDEX.md` (newest first). English slug.
