# Examples (not the default product)

Public examples describe the process, not a clone-owner's body. Filled profiles,
fusion proportions, menu values and plugin winners stay in gitignored
`maps/<avatar>/`. A foreign clone must not require a private example file.

For a new named body, start from `maps/templates/` through
`python maps/init_avatar.py <avatar>`. Record source/target body identity, resolve
actual hierarchy paths, and leave unknown mappings unresolved until a dump proves
them. Never copy menu integers, rest poses or fit claims from another profile.

Live facts for *your* body: gitignored `maps/<avatar>/`. How-to: [../avatar-intake.md](../avatar-intake.md) · [docs/AVATAR_PROFILE.md](../../../../docs/AVATAR_PROFILE.md).
