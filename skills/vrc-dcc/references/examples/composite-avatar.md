# Example composite avatar (synthetic)

**Synthetic / example only.** Id: `example-composite`. There is **no** corresponding user Unity project and no handshake default.

This page teaches structure. It is not a clone-owner body, not a Booth SKU, and not anonymized production notes.

## What it is allowed to teach

1. **Two source bodies ≠ the composite target.** Clothes or menus built for source-A or source-B do not automatically fit `example-composite`. Shop size charts for either source are data, not this mesh.
2. **An empty source expression menu does not mean the built avatar has no menu.** Prefab installers, Modular Avatar MenuInstaller, and leftover vendor FX can add controls after merge. Dump the *built* menu, not only the source prefab.
3. **Geometry fit and control-chain acceptance are different checks.** Weights / visemes / nipple morphs are mesh. Outfit Int, strip Bools, and PhysBone lanes are control. Passing one does not prove the other.

## What this page must not contain

Real dates, private parameter packs, live Hierarchy paths from a named shop character, or “installed on the author’s body” status.
