# Security Policy

This repo ships templates, manifests, and PowerShell. It ships **no** game binaries and **no** VRChat credentials.

In scope: `scripts/bootstrap.ps1` writing outside the install root, leaking `local.json` into git, or instructing an agent to store SDK cookies.

**Do not open a public issue for credential leaks.** Use GitHub private vulnerability reporting.

Responsible use: authorized avatar/world work. Agents must not click VRChat Build & Publish.
