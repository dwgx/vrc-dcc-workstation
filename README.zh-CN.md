# vrc-dcc-workstation（中文）

便携 **VRChat DCC** 骨架仓库：Blender 5.x（网格/权重/口型）+ Unity 2022.3（Modular Avatar / NDMF / PhysBone / 菜单）。不含第三方二进制、不含工程。

克隆后先读 `AGENTS.md` 握手，再读 `docs/WORKFLOW.md`，然后 `scripts\bootstrap.ps1`（默认 dry-run）。MCP 只挂当前任务，禁止写进 Claude/Codex/Cursor/Grok **用户全局**配置。VRChat **Build & Publish** 必须人点。

英文 `README.md` 为对外正文。本机绝对路径写在 gitignore 的 `LOCAL-THIS-PC.md` / `local.json`，不要推进 GitHub。
