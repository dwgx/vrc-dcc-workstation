This repository is a **skeleton / bootstrap**. It does **not** ship Blender, Unity, the VRChat SDK, Modular Avatar, avatar projects, or MCP server binaries.

Pins in `manifests/tools.json` point at **official** PyPI/GitHub/VPM sources. You fetch those yourself (or authorize an agent after the handshake).

**VRChat SDK Build & Publish must stay human.** Do not store SDK cookies in this repo, in notes, or in chat logs you intend to commit.

Official Unity MCP / Unity 6 AI Assistant is the wrong stack for a **2022.3** avatar project. There is no live package named “UnityMCP-VCC”.

Use on avatars and worlds you are allowed to edit. Authors are not responsible for TOS violations or lost uploads.
