## 배치

| 종류 | 영어（정본） | 현지화 형제 파일 |
|---|---|---|
| 랜딩 | `README.md` | `README.zh-CN.md`, `README.ja.md`, `README.ko.md` |
| 에이전트 계약 | `AGENTS.md` | `AGENTS.zh-CN.md`, `AGENTS.ja.md`, `AGENTS.ko.md` |
| 법적 고지 | `DISCLAIMER.md` | `DISCLAIMER.zh-CN.md`, `DISCLAIMER.ja.md`, `DISCLAIMER.ko.md` |
| 초기화 설문 | `templates/INIT_QUESTIONNAIRE.md` | `templates/i18n/<locale>/INIT_QUESTIONNAIRE.md` |
| 작업 초기화 | `templates/JOB.md` | `templates/i18n/<locale>/JOB.md` (zh-CN, ja) |
| 아바타 프로젝트 포인터 | `templates/avatar-project/` | 선택. `COPY.md`. `session-probe` `kind: dcc`가 있으면 복사 불필요. |
| 기타 문서 | `docs/*.md` | 번역이 있으면 `docs/i18n/<locale>/` |
| 주인 오버레이 | `OWNER.example.md` | gitignore된 `OWNER.md`（주인 언어. 필수 번역 아님） |
| 계약 평가 | `docs/EVAL.md` | 영어만（테스트와 같음. 번역하지 않음） |

`locales.json`은 기계가 읽는 BCP-47 목록입니다. 파일 이름은 GitHub에서 흔한 `zh-CN`을 쓰고 `zh-Hans`는 쓰지 않습니다. 번체（`zh-TW` / `zh-HK` / `zh-Hant`）는 해석 시 `zh-CN`으로 떨어집니다（독립 번체 파일은 아직 없음）.

코드 펜스, 명령, 패키지 이름, GitHub URL은 **번역하지 않습니다**.

## 초기화 때 에이전트가 할 일

1. 로케일을 이 순서로 결정: **사용자가 이미 쓰고 있는 언어** → `local.json`의 `ui_language` → 환경 변수 `WORKSTATION_UI_LANG` / `VRC_DCC_UI_LANG` → Windows UI 문화권 → `en`.
2. 대응하는 `AGENTS.<locale>.md`(없으면 `AGENTS.md`). **설치:** 설문. **아바타 / DCC 작업:** `templates/JOB.md` (의도로 분류. 암호 문구 금지). **월드 / Udon:** `skills/vrc-world`(영어 초안; `docs/WORLD.md`). `OWNER.md`가 있으면 읽는다. 파이프라인은 `docs/i18n/<locale>/WORKFLOW.md`.
3. **그 언어로 대화한다.** 아직 모호하면 Q0을 묻는다.
4. 핸드셰이크 뒤에 gitignore된 `local.json`에 `ui_language`를 남긴다（`Save-WorkstationLocale`, 또는 에이전트가 필드를 씀）. `scripts/bootstrap.ps1 -Apply`는 `local.json`이 없으면 example을 복사한다. 언어를 쓰는 것은 `WORKSTATION_UI_LANG` / `VRC_DCC_UI_LANG`가 이미 있을 때만. 영어 OS UI가 중·일·한 대화를 고정하지 않게 한다. 비어 있지 않은 값은 덮어쓰지 않는다.
5. **git 커밋 메시지는 영어.** `local.json`은 커밋하지 않는다.

`scripts/resolve-locale.ps1`이 bootstrap에서 같은 순서를 구현합니다.

## 사람용

각 README 맨 위의 언어 막대를 쓰세요. `docs/i18n/` 아래 깊은 페이지도 형제 번역을 가리킵니다.

파이프라인 페이지（`WORKFLOW`, `UNITY`, `ATTACH`, `RULES`, `AI_USAGE_GUIDE`）에는 번역이 있습니다. 스킬 본문은 영어（도구 이름 자동 검색용）. **대화는 해석된 로케일을 따릅니다.**

## 언어 추가

1. `locales.json`에 태그를 넣는다.
2. README / AGENTS / DISCLAIMER / 설문을 번역한다.
3. `docs/I18N.md`를 `docs/i18n/<locale>/I18N.md`로 옮긴다.
4. 최소한 `WORKFLOW.md`를 동기화한다. 절 순서는 영어와 같게. 모든 변종의 `<!-- I18N:START -->`를 갱신한다.
