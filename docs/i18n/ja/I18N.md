# 国際化（I18N）

GitHub はブラウザ言語で README を**自動切替しません**。このテンプレートは**英語を正文**とし、簡体字中国語・日本語・韓国語の**全文対訳**を同梱します（VRChat / 東アジア向け）。

## 配置

| 種類 | 英語（正文） | 対訳 |
|---|---|---|
| ランディング | `README.md` | `README.zh-CN.md`、`README.ja.md`、`README.ko.md` |
| エージェント契約 | `AGENTS.md` | `AGENTS.zh-CN.md`、`AGENTS.ja.md`、`AGENTS.ko.md` |
| 法務 | `DISCLAIMER.md` | `DISCLAIMER.zh-CN.md`、`DISCLAIMER.ja.md`、`DISCLAIMER.ko.md` |
| 初期化ヒアリング | `templates/INIT_QUESTIONNAIRE.md` | `templates/i18n/<locale>/INIT_QUESTIONNAIRE.md` |
| ジョブ初期化 | `templates/JOB.md` | `templates/i18n/<locale>/JOB.md`（zh-CN、ja） |
| アバター工程ポインタ | `templates/avatar-project/` | 任意。`COPY.md`。`session-probe` `kind: dcc` があるマシンはコピー不要。 |
| その他 | `docs/*.md` | 訳があるとき `docs/i18n/<locale>/` |
| 所有者オーバーレイ | `OWNER.example.md` | gitignore の `OWNER.md`（所有者の言語。対訳必須ではない） |
| 契約チェック | `docs/EVAL.md` | 英語のみ（テストと同じ。対訳しない） |

`locales.json` は機械が読む BCP-47 一覧です。ファイル名は GitHub で多い `zh-CN` を使い、`zh-Hans` にはしません。繁体字（`zh-TW` / `zh-HK` / `zh-Hant`）は解決時に `zh-CN` へ落とします（独立ファイルは未用意）。

コードフェンス、コマンド、パッケージ名、GitHub URL は**訳しません**。

## 初期化でエージェントがやること

1. ロケールをこの順で決める：**いまユーザーが話している言語** → `local.json` の `ui_language` → 環境変数 `WORKSTATION_UI_LANG` / `VRC_DCC_UI_LANG` → Windows の UI カルチャ → `en`。
2. 対応する `AGENTS.<locale>.md`（無ければ `AGENTS.md`）。**インストール：** ヒアリング。**アバター / DCC 作業：** `templates/JOB.md`（意図で分類。合言葉は作らない）。**ワールド / Udon：** `skills/vrc-world`（英語スタブ；`docs/WORLD.md`）。`OWNER.md` があれば読む。手順は `docs/i18n/<locale>/WORKFLOW.md`。
3. **その言語で会話する。** まだ曖昧なら Q0 を聞く。
4. ヒアリング後に gitignore の `local.json` へ `ui_language` を残す（`Save-WorkstationLocale`、またはエージェントが書く）。`scripts/bootstrap.ps1 -Apply` は `local.json` が無ければ example からコピーする。言語を書くのは `WORKSTATION_UI_LANG` / `VRC_DCC_UI_LANG` が既にあるときだけ。英語の OS UI で中日韓の会話を固定しない。空でない値は上書きしない。
5. **git のコミットメッセージは英語。** `local.json` はコミットしない。

`scripts/resolve-locale.ps1` が bootstrap で同じ順を実装します。

## 人向け

各 README 先頭の言語バーを使う。`docs/i18n/` の深いページも兄弟へリンクする。

管線ページ（`WORKFLOW`、`UNITY`、`ATTACH`、`RULES`、`AI_USAGE_GUIDE`）には対訳がある。スキル本文は英語のまま（ツール名の自動検出のため）。**会話は解決したロケールに従う。**

## 言語を足す

1. `locales.json` にタグを足す。
2. README / AGENTS / DISCLAIMER / ヒアリングを訳す。
3. `docs/I18N.md` を `docs/i18n/<locale>/I18N.md` へ。
4. 少なくとも `WORKFLOW.md` を同期する。見出し順は英語と同じ。各変体の `<!-- I18N:START -->` を更新する。
