# 国际化（I18N）

GitHub **不会**按浏览器语言自动换 README。本模板以**英文为正文**，并提供简体中文、日文、韩文的**完整对照文档**（面向 VRChat / 东亚用户）。

## 布局

| 类型 | 英文（正文） | 本地化兄弟文件 |
|---|---|---|
| 首页 | `README.md` | `README.zh-CN.md`、`README.ja.md`、`README.ko.md` |
| Agent 合同 | `AGENTS.md` | `AGENTS.zh-CN.md`、`AGENTS.ja.md`、`AGENTS.ko.md` |
| 法律 | `DISCLAIMER.md` | `DISCLAIMER.zh-CN.md`、`DISCLAIMER.ja.md`、`DISCLAIMER.ko.md` |
| 初始化问卷 | `templates/INIT_QUESTIONNAIRE.md` | `templates/i18n/<locale>/INIT_QUESTIONNAIRE.md` |
| 其它文档 | `docs/*.md` | 有译文时放 `docs/i18n/<locale>/` |

`locales.json` 是机器可读的 BCP-47 列表。文件名用 `zh-CN`（GitHub 上常见），不用 `zh-Hans`。繁体中文（`zh-TW` / `zh-HK` / `zh-Hant`）解析时回落到 `zh-CN`，目前没有独立繁体文件。

代码块、命令、包名、GitHub URL **不翻译**。

## Agent 初始化必须做的事

1. 按此顺序解析语言：**用户已经在说的语言** → `local.json` 的 `ui_language` → 环境变量 `WORKSTATION_UI_LANG` / `VRC_DCC_UI_LANG` → Windows UI 区域 → `en`。
2. 读对应的 `AGENTS.<locale>.md`（没有则 `AGENTS.md`）和对应问卷。管线步骤读 `docs/i18n/<locale>/WORKFLOW.md`。
3. **用该语言对话。** 仍不确定时问 Q0。
4. 握手后把 `ui_language` 写入 gitignore 的 `local.json`（`Save-WorkstationLocale`，或 agent 写该字段）。`scripts/bootstrap.ps1 -Apply` 在缺少 `local.json` 时从 example 复制；**只有**已设置 `WORKSTATION_UI_LANG` / `VRC_DCC_UI_LANG` 时才写入语言，避免英文系统 UI 把中日韩对话锁死。已有非空值时不要覆盖。
5. **git 提交说明保持英文。** 不要提交 `local.json`。

`scripts/resolve-locale.ps1` 对 bootstrap 实现同一顺序。

## 给人看

每个 README 顶部有语言条。`docs/i18n/` 下的深层页面同样指向兄弟译文。

管线页（`WORKFLOW`、`UNITY`、`ATTACH`、`RULES`、`AI_USAGE_GUIDE`）有译文。技能正文保持英文，以便工具名可被自动发现；**对话仍跟解析出的语言走**。

## 加一种语言

1. 把标签加进 `locales.json`。
2. 翻译 README / AGENTS / DISCLAIMER / 问卷。
3. 把 `docs/I18N.md` 译到 `docs/i18n/<locale>/I18N.md`。
4. 至少同步 `WORKFLOW.md`。章节顺序与英文一致。更新每种变体里的 `<!-- I18N:START -->` 选择条。
